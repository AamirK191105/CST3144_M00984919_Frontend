# CST3144_M00984919_Frontend

Coursework 1 Front End.

CSS for this coursework was handled by AI as it is not a requirement in the rubric and permission has been granted by the teacher.

- After School Hobbies Store interface
- Vue.js-powered single-page application
- Product listing with:
  - Product name
  - Description
  - Location
  - Price in pounds
  - Available spaces
  - Star rating out of five
  - Product-specific icons
- Add products to the shopping cart
- Prevent adding products when no spaces remain
- Display stock status:
  - Items in stock
  - Limited availability
  - All out
- Cart item count displayed in the checkout button
- Remove products from the cart
- Display cart item prices and locations
- Calculate and display the cart total
- Toggle between the product listing and checkout views
- Sort products by price:
  - Ascending
  - Descending
- Sort products by location:
  - Ascending
  - Descending
- Sort products by name:
  - Ascending
  - Descending
- Sort products by number of spaces:
  - Ascending
  - Descending
- Checkout form containing:
  - First name
  - Last name
  - Address
  - Area
  - Post code
  - County selection
  - Gift checkbox
  - Home delivery option
  - Store pickup option
- Live order information preview
- Validation requiring customer details before submission
- Prevent placing an order with an empty cart
- Order confirmation alert after submitting a valid order
- Font Awesome icons for products, ratings, and the cart
- Responsive viewport configuration for different screen sizes
